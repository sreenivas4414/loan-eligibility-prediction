Loan Eligibility Prediction

Project Overview

This project uses Machine Learning to predict whether a loan applicant is eligible for a loan based on applicant information.

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- HTML and CSS
- Jupyter Notebook

Project Structure

- "app.py" — Flask application
- "setup_db.py" — Database setup script
- "model.ipynb" — Model development notebook
- "loan_model.pkl" — Saved machine learning model
- "templates/index.html" — Main application page
- "templates/dashboard.html" — Dashboard page

How to Run

1. Install the required Python libraries.
2. Run the Flask application using "python app.py".
3. Open the local URL shown in the terminal.

Purpose

This project demonstrates the use of machine learning for loan eligibility prediction and a web interface for interacting with the model.
